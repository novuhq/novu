---
title: "Track activity and engagement events"
openapi: "POST /v2/inbound-webhooks/delivery-providers/{environmentId}/{integrationId}"
---

<Note>
  This endpoint is used by email providers to deliver activity and engagement events to Novu. It is available on **Novu Cloud** and **Enterprise self-hosted** only. It is not available on Community self-hosted edition. See [Activity Tracking](/platform/integrations/email/activity-tracking) for more information.
</Note>
