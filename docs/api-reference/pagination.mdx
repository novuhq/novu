---
title: 'Pagination'
description: 'Page through large Novu API list responses using page-based, offset-based, and cursor-based pagination.'
---

List endpoints return results in pages so you can retrieve large collections efficiently. Novu uses three pagination styles depending on the endpoint and API version. Each style accepts query parameters to control the page size and position, and returns a response envelope with the page of results plus metadata.

## Pagination styles

| Style | Query parameters | Used by |
| --- | --- | --- |
| **Page-based** | `page`, `limit` | v1 lists such as subscribers, messages, topics, and activity |
| **Offset-based** | `limit`, `offset` | v2 lists such as workflows and layouts |
| **Cursor-based** | `after`, `before`, `limit` | v2 lists such as subscribers, topics, contexts, and channel endpoints |

<Tip>
  Prefer cursor-based pagination for large or frequently changing datasets. Cursors stay stable as items are added or removed, so you avoid skipped or duplicated results that can occur with page or offset pagination.
</Tip>

## Page-based pagination

Page-based endpoints accept a zero-based `page` and a `limit` (the number of items per page).

| Parameter | Type | Default | Notes |
| --- | --- | --- | --- |
| `page` | number | `0` | Zero-based page index. |
| `limit` | number | `10` | Items per page. Maximum `100`. |

The response wraps the page in an envelope:

```json
{
  "data": [ /* array of items */ ],
  "page": 0,
  "pageSize": 10,
  "hasMore": true,
  "totalCount": 248
}
```

| Field | Description |
| --- | --- |
| `data` | The array of items for the current page. |
| `page` | The zero-based index of the returned page. |
| `pageSize` | The number of items requested per page. |
| `hasMore` | Whether more pages are available after this one. |
| `totalCount` | Total number of matching items. Returned by some endpoints. |

To fetch the next page, increment `page` until `hasMore` is `false`:

```bash
curl -G https://api.novu.co/v1/subscribers \
  --header 'Authorization: ApiKey <NOVU_SECRET_KEY>' \
  --data-urlencode 'page=1' \
  --data-urlencode 'limit=20'
```

## Offset-based pagination

Offset-based endpoints accept a `limit` and an `offset` (the number of items to skip). They also support sorting through `orderBy` and `orderDirection`.

| Parameter | Type | Default | Notes |
| --- | --- | --- | --- |
| `limit` | number | endpoint default | Items to return. |
| `offset` | number | `0` | Items to skip before returning results. |
| `orderBy` | string | — | Field to sort by (endpoint-specific). |
| `orderDirection` | string | — | `ASC` or `DESC`. |

Advance through results by increasing `offset` in increments of `limit`:

```bash
curl -G https://api.novu.co/v2/workflows \
  --header 'Authorization: ApiKey <NOVU_SECRET_KEY>' \
  --data-urlencode 'limit=20' \
  --data-urlencode 'offset=40'
```

## Cursor-based pagination

Cursor-based endpoints return opaque cursors that point to the position after the last item (`next`) and before the first item (`previous`) of the current page.

| Parameter | Type | Notes |
| --- | --- | --- |
| `limit` | number | Items per page. |
| `after` | string | Cursor to fetch the page after a position. Use the `next` cursor from a previous response. |
| `before` | string | Cursor to fetch the page before a position. Use the `previous` cursor from a previous response. |
| `orderBy` | string | Field to sort by (endpoint-specific). |
| `orderDirection` | string | `ASC` or `DESC`. |
| `includeCursor` | boolean | Include the cursor item itself in the results. |

The response envelope returns the cursors and total count:

```json
{
  "data": [ /* array of items */ ],
  "next": "eyJpZCI6IjY1...",
  "previous": null,
  "totalCount": 1240,
  "totalCountCapped": false
}
```

| Field | Description |
| --- | --- |
| `data` | The array of items for the current page. |
| `next` | Cursor for the next page, or `null` if this is the last page. |
| `previous` | Cursor for the previous page, or `null` if this is the first page. |
| `totalCount` | Total matching items, counted up to a maximum of 50,000. |
| `totalCountCapped` | `true` when more than 50,000 results match and `totalCount` is capped. |

To page forward, pass the `next` cursor as `after` on the following request. Stop when `next` is `null`:

```bash
curl -G https://api.novu.co/v2/subscribers \
  --header 'Authorization: ApiKey <NOVU_SECRET_KEY>' \
  --data-urlencode 'limit=50' \
  --data-urlencode 'after=eyJpZCI6IjY1...'
```

## Fetch all pages

This example walks every page of a cursor-based list with the TypeScript SDK until there are no more results:

```javascript
import { Novu } from '@novu/api';

const novu = new Novu({ secretKey: process.env.NOVU_SECRET_KEY });

async function listAllSubscribers() {
  const all = [];
  let after;

  do {
    const { result } = await novu.subscribers.list({ limit: 100, after });
    all.push(...result.data);
    after = result.next ?? undefined;
  } while (after);

  return all;
}
```
