Use Slack as a messaging channel for your agent. Users can DM the bot or @mention it in a channel or group DM. Novu keeps thread context, shows typing and plan cards during the turn, can attach files on replies, and can post Approve / Deny cards before gated tools run. Connect it from the [Setup](#setup) section.

## Examples

### Inbound thread

A user @mentions the agent in a thread. Novu adds an eyes reaction, shows typing and a plan card while the agent runs tools, then replies in the same thread with optional action buttons.

### Tool approval

When a tool is gated, Slack shows a native approval block (**Deny**, **Approve once**, **Always allow this tool**). The handler resumes after the user selects an option.

## Where the agent replies

The agent treats a 1:1 DM differently from a conversation with several people in it.

- **1:1 DM:** the agent replies to every message.
- **Channel or group DM:** the agent replies only to messages that @mention it, and it answers in a thread under that message. It ignores everything else. A group DM follows the channel rules because it has more than one person in it.

The Slack app must be a member of the channel or group DM. Until you add it, the agent does not receive messages from that conversation.

### Reply policy

An @mention brings the agent into a thread. The reply policy then controls whether it answers follow-up messages in that thread without another @mention. It has no effect in 1:1 DMs.

Set it in the dashboard under **Agent behavior** > **Reply policy**.

| Reply policy | What the agent does in the thread |
| --- | --- |
| **Mention only** | Replies only to messages that @mention it. |
| **Auto-reply in threads** | Replies to every message. |
| **Smart** | Replies to every message while one person is talking to it. When a second person posts, it asks to be @mentioned and then replies only to @mentions. |

**Smart** also falls back to @mentions when another agent joins the thread or the person @mentions a teammate.

New agents default to **Smart**. Agents created before this setting existed use **Auto-reply in threads**.

### Reply from your code

Your handler does not need to know which kind of conversation it is in. `ctx.reply()` posts to the conversation that triggered the handler. To reply from another backend, call the [Send an agent reply](/api-reference/agents/send-an-agent-reply) API with the `conversationId`. Either way, Novu posts the reply in that conversation's Slack thread.

## Create a Slack app

When the dashboard or CLI asks for a Slack App Configuration Token:

1. Open [Slack API apps](https://api.slack.com/apps).
2. Under **Your App Configuration Tokens**, click **Generate Token**.

 ![Generate Slack token](/images/agents/quickstart/generate-slack-token.png)

3. Select your workspace and click **Generate**.
4. Copy the token (starts with `xoxe.xoxp-`) and paste it into Novu or the CLI.
5. Finish the install / Allow flow in Slack.

 ![Install app](/images/agents/quickstart/install-app.png)

The configuration token is used once to create the Slack app. Novu does not store it.

## Distribute to other workspaces

A Slack app only works in the workspace where it was created. Users in any other workspace are blocked when they click your connect button until you enable Public Distribution.

1. Open your app in [Slack API apps](https://api.slack.com/apps).
2. Go to **Manage Distribution**.
3. Complete the checklist and click **Activate Public Distribution**.

Novu does not turn this on for you. Public Distribution is a manual setting in Slack, and the app manifest that Novu generates leaves it off.

## Connect component

Use `SlackConnectButton` from `@novu/react` so end users can install the Slack app and link it to your agent from your product UI. Render it on an authenticated page and pass the signed-in user's id as `subscriberId`. See [Connect components in production](/agents/custom-code-agent/connect-components#use-connect-components-in-production).

```tsx
import { NovuProvider, SlackConnectButton } from '@novu/react';

// userId: the signed-in user's id from your app's auth session
export function SlackConnect({ userId }: { userId: string }) {
  const subscriberId = userId;
  const integrationIdentifier = 'slack-integration-identifier';
  const agentIdentifier = 'agent-identifier';

  return (
    <NovuProvider
      applicationIdentifier={process.env.NEXT_PUBLIC_NOVU_APPLICATION_IDENTIFIER!}
      subscriberId={subscriberId}
    >
      <SlackConnectButton
        integrationIdentifier={integrationIdentifier}
        connectionIdentifier={`${subscriberId}:${integrationIdentifier}:${agentIdentifier}`}
        connectionMode="subscriber"
        connectLabel="Install agent ↗"
        connectedLabel="Connected to Slack"
        onConnectSuccess={() => {
          // Workspace linked
        }}
        onConnectError={(error: unknown) => {
          console.error(error);
        }}
      />
    </NovuProvider>
  );
}
```

Props and appearance options: [Connect components](/agents/custom-code-agent/connect-components#slack-connect-button).
