Build a [LangChain](https://docs.langchain.com/) agent with Novu Connect. You return a LangChain agent config from `onMessage`. Novu runs the agent and delivers replies on Slack, Microsoft Teams, WhatsApp, Telegram, or email.

This walkthrough uses **Slack** for the first connection. The same handler works on other channels once you link them.

## What do I need before I start?

- A [Novu account](https://dashboard.novu.co)
- Node.js 22+
- A Slack workspace where you can install apps (or another [supported channel](/agents/get-started/agents-and-providers))
- An `OPENAI_API_KEY` (or another [LangChain provider](https://docs.langchain.com/oss/javascript/integrations/providers) key)

## How do I get a working agent?

<Steps>

<Step>

## Run the CLI

In an empty folder:

```bash
npx novu connect
```

When prompted:

1. Sign in to Novu (or paste your secret key).
2. Choose **LangChain** as the runtime.
3. Name your agent. Note the **identifier** the CLI prints. Your code must use the same value.
4. When asked how to authenticate the model, pick **OpenAI** (or Anthropic) and paste your API key. That wires the LangChain config in the scaffold. If you skip this step, the project starts as a demo echo agent until you add a key later.
5. Choose **Slack** (or another channel).

</Step>

<Step>

## Connect Slack

When the CLI asks for a Slack App Configuration Token:

1. Open [Slack API apps](https://api.slack.com/apps).
2. Under **App Configuration Tokens**, click **Generate Token**.
3. Select your workspace, generate the token, and copy it (it starts with `xoxe.xoxp-`).
4. Paste it into the CLI and finish the install / Allow flow in Slack.

The token is used once to create the Slack app. Novu does not store it.

For screenshots of this flow, see [Create a Slack app](/agents/custom-code-agent/quickstart#create-a-slack-app) in the custom code quickstart.

</Step>

<Step>

## Accept the scaffold

Confirm creating a starter project when the CLI asks. It creates a Next.js app with:

- `app/api/novu/route.ts` (bridge endpoint)
- `app/novu/agents/` (your handler)
- `.env.local` with `NOVU_SECRET_KEY`
- `npm run dev:novu`

If you already have an app and skipped the scaffold, jump to [Wire an existing app](#wire-an-existing-app).

</Step>

<Step>

## Run the agent locally

```bash
npm run dev:novu
```

This starts your app and tunnels it to Novu so channel messages reach your bridge. Keep the process running.

If the script is missing:

```bash
npx novu dev --port 4000
```

</Step>

<Step>

## Send a message

Message your bot in Slack (DM or @mention). You should get a reply from your LangChain handler in the same thread.

**Success looks like:** the tunnel is connected, and the reply is from your model (not a static demo card), after you authenticated the LLM in the CLI or set `OPENAI_API_KEY` in `.env.local`.

If nothing comes back:

- Confirm `npm run dev:novu` is still running.
- Confirm the agent identifier in code matches the dashboard.
- Confirm your model API key is set (for example `OPENAI_API_KEY`).
- Confirm Slack install completed and you are messaging the correct bot.

</Step>

</Steps>

## Wire an existing app

Use this only if you skipped the CLI scaffold. Otherwise you can skip this section.

<AccordionGroup>
  <Accordion title="Install packages and env">
```bash
npm install @novu/framework langchain @langchain/core @langchain/openai
```

Add to `.env.local`:

```bash
OPENAI_API_KEY=sk-...
NOVU_SECRET_KEY=your-novu-secret-key
```

Copy `NOVU_SECRET_KEY` from **API Keys** in the dashboard if needed.
  </Accordion>
  <Accordion title="Create the agent handler">
Create `app/novu/agents/<your-identifier>.ts` using the identifier from the dashboard:

```typescript
import { ChatOpenAI } from '@langchain/openai';
import { agent } from '@novu/framework/langchain';

export const supportBot = agent('support-bot', {
  onMessage: async (_message, ctx) => ({
    model: new ChatOpenAI({ model: 'gpt-4o' }),
    system: 'You are a helpful support agent. Keep answers short.',
  }),
});
```

Export it from `app/novu/agents/index.ts`:

```typescript
export { supportBot } from './support-bot';
```

Match `agent('...')` to the dashboard **Identifier**. Returning `{ model, system }` is a `LangChainAgentConfig` — Novu calls `createAgent().invoke()` and delivers the final text. Novu maps `ctx.history` for you on this path.

Prefer a `Chat*` instance for `model`. Model strings like `'openai:gpt-4o'` need LangChain listed in Next.js `serverExternalPackages` — see [Next.js and Turbopack](/agents/custom-code-agent/frameworks/langchain#nextjs-and-turbopack).
  </Accordion>
  <Accordion title="Add a tool (optional)">
```typescript
import { tool } from '@langchain/core/tools';
import { ChatOpenAI } from '@langchain/openai';
import { agent } from '@novu/framework/langchain';
import { z } from 'zod';

const lookupOrder = tool(
  async ({ orderId }) => ({ orderId, status: 'shipped' }),
  {
    name: 'lookupOrder',
    description: 'Look up an order by ID',
    schema: z.object({ orderId: z.string() }),
  },
);

export const supportBot = agent('support-bot', {
  onMessage: async (_message, ctx) => ({
    model: new ChatOpenAI({ model: 'gpt-4o' }),
    system: 'You are a helpful support agent. Use lookupOrder when the user asks about an order.',
    tools: [lookupOrder],
  }),
});
```
  </Accordion>
  <Accordion title="Add the bridge route">
Create `app/api/novu/route.ts`:

```typescript
import { serve } from '@novu/framework/next';
import { supportBot } from '../../novu/agents';

export const { GET, POST, OPTIONS } = serve({
  agents: [supportBot],
});
```

Then run `npx novu dev` (or `npm run dev:novu`) and message the bot. For Express, Hono, and other servers, see [Connecting your app](/agents/custom-code-agent/connecting-your-app).
  </Accordion>
</AccordionGroup>

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Which channels can I use with a LangChain agent?">
    Slack, Microsoft Teams, WhatsApp, Telegram, and email. One handler works for all of them. See [Agents and providers](/agents/get-started/agents-and-providers).
  </Accordion>
  <Accordion title="Does Novu run LangChain for me?">
    When you return a `LangChainAgentConfig`, yes. Novu invokes `createAgent()` with your model, system prompt, and tools, then posts the final text to the channel. If you invoke a graph yourself and return `{ messages }`, Novu only delivers the text.
  </Accordion>
  <Accordion title="How do I gate a tool behind user approval?">
    Set `needsApproval` on the config (for example `(toolCall) => toolCall.name === 'issueRefund'`). Novu posts Approve / Deny in the conversation and resumes from history. See the [LangChain reference](/agents/custom-code-agent/frameworks/langchain#automatic-tool-approval).
  </Accordion>
  <Accordion title="When should I use toLangChainMessages?">
    Only when you call `createAgent().invoke()` (or a graph) yourself inside `onMessage`. If you return a config object, Novu maps history for you.
  </Accordion>
  <Accordion title="I skipped LLM auth in the CLI. What now?">
    Add `OPENAI_API_KEY` (or your provider key) to `.env.local`, then update `app/novu/agents/` so `onMessage` returns a LangChain config (`model`, `system`, optional `tools`). Restart `npm run dev:novu`.
  </Accordion>
  <Accordion title='I get "Cannot find module as expression is too dynamic"'>
    Next.js Turbopack cannot resolve LangChain's dynamic provider imports for model strings. Pass a chat model instance (`new ChatOpenAI({ model: 'gpt-4o' })`) or add LangChain packages to `serverExternalPackages` in `next.config.mjs`. See [Next.js and Turbopack](/agents/custom-code-agent/frameworks/langchain#nextjs-and-turbopack).
  </Accordion>
</AccordionGroup>

## Set this up with an AI assistant

<Prompt description="Build a LangChain agent with Novu Connect" icon="plug" actions={["copy", "cursor"]}>
# Build a LangChain agent with Novu Connect

Follow https://docs.novu.co/agents/get-started/langchain

## Goal

Create a Novu custom code agent that replies on messaging channels using LangChain. Prefer the CLI happy path: `npx novu connect`, LangChain runtime, LLM auth, Slack, scaffold, then `npm run dev:novu`.

## Rules

ALWAYS:

- Match `agent('id')` to the Novu dashboard agent Identifier
- Return a LangChainAgentConfig so Novu can invoke the agent
- Keep handlers channel-agnostic
- Follow the project's package manager and TypeScript conventions

NEVER:

- Hardcode API keys
- Rebuild conversation history manually when returning a config

</Prompt>
