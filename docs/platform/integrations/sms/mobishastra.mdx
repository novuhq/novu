You can use [Mobishastra](https://telkosh.com/mobishastra/) to send SMS messages through Novu.

## Getting started

1. Get a Mobishastra / Telkosh account with API access enabled.
2. Copy the API **Base URL** your account manager provides.
3. Copy the **Username** and **Password** for API authentication.
4. Confirm the sender ID Mobishastra allows for your traffic.

## Creating a Mobishastra integration with Novu

1. Visit the [Integrations](https://dashboard.novu.co/integrations?utm_campaign=docs-sms-mobishastra) page on Novu.
2. Click **Add a provider**.
3. Locate **Mobishastra** under the SMS section and click **Connect**.
4. Enter your:
   - **Base URL**
   - **Username**
   - **Password**
   - **From** (approved sender ID)
5. Confirm **Active Integration** is on. New integrations start active by default.
6. Click **Create Integration**.

You can now send SMS notifications with Mobishastra through Novu.
