You can use [Afro Message](https://afromessage.com/developers) to send SMS messages through Novu.

## Getting started

1. Create or log in to your Afro Message account.
2. Copy your **API Key** from the developer console.
3. Choose a **Sender Name** that Afro Message has approved for your account.

## Creating an Afro Message integration with Novu

1. Visit the [Integrations](https://dashboard.novu.co/integrations?utm_campaign=docs-sms-afro-message) page on Novu.
2. Click **Add a provider**.
3. Locate **Afro Message** under the SMS section and click **Connect**.
4. Enter your:
   - **API Key**
   - **Sender Name**
   - **From** (sender ID Novu should use on outbound messages)
5. Confirm **Active Integration** is on. New integrations start active by default.
6. Click **Create Integration**.

You can now send SMS notifications with Afro Message through Novu.
