You can use iMedia to send SMS messages through Novu.

## Getting started

1. Get API access from your iMedia account contact.
2. Copy your **API Token**.
3. Confirm the sender ID iMedia expects for outbound SMS.

## Creating an iMedia integration with Novu

1. Visit the [Integrations](https://dashboard.novu.co/integrations?utm_campaign=docs-sms-imedia) page on Novu.
2. Click **Add a provider**.
3. Locate **iMedia** under the SMS section and click **Connect**.
4. Enter your:
   - **API Token**
   - **From** (approved sender ID)
5. Confirm **Active Integration** is on. New integrations start active by default.
6. Click **Create Integration**.

You can now send SMS notifications with iMedia through Novu.
