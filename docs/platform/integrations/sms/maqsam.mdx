You can use [Maqsam](https://maqsam.com/) to send SMS messages to your customers through Novu.

## Getting started

To use Maqsam in the SMS channel, create a Maqsam account and add your access key ID and access secret to the Maqsam integration in Novu.

Contact `support@maqsam.com` to enable the API feature for your account. After that, generate an `access_key_id` and `access_secret` pair from your account settings. See Maqsam's [SMS API docs](https://portal.maqsam.com/docs/v2/sms) for details.

## Creating a Maqsam integration with Novu

1. Visit the [Integrations](https://dashboard.novu.co/integrations?utm_campaign=docs-sms-maqsam) page on Novu.
2. Click **Add a provider**.
3. Locate **Maqsam** under the SMS section and click **Connect**.
4. Enter your:
   - **Access Key ID**
   - **Access Secret**
   - **From** (your Maqsam sender ID)
5. Confirm **Active Integration** is on. New integrations start active by default.
6. Click **Create Integration**.

You can now send SMS notifications with Maqsam through Novu.
