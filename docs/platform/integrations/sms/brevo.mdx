You can use [Brevo transactional SMS](https://developers.brevo.com/reference/sendtransacsms) to send SMS messages through Novu.

This is separate from the Brevo email integration. Add Brevo under the SMS channel when you want Brevo to deliver SMS steps.

## Getting started

1. [Sign up](https://www.brevo.com/) or log in to Brevo.
2. Open [API Keys](https://app.brevo.com/settings/keys/api) and create or copy an API key with SMS permissions.
3. Set up an SMS sender in Brevo for the countries you send to. Local rules for sender IDs still apply.

## Creating a Brevo SMS integration with Novu

1. Visit the [Integrations](https://dashboard.novu.co/integrations?utm_campaign=docs-sms-brevo) page on Novu.
2. Click **Add a provider**.
3. Locate **Brevo** under the SMS section and click **Connect**.
4. Enter your:
   - **API Key**
   - **From** (Brevo SMS sender name or number)
5. Confirm **Active Integration** is on. New integrations start active by default.
6. Click **Create Integration**.

You can now send SMS notifications with Brevo through Novu.
