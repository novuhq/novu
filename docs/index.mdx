## Two products, one platform

Novu does two things from a single open-source foundation:

<Columns cols={2}>
  <Card title="Platform" icon="layout-dashboard" href="/platform">
    **Notifications your product sends to users.** Workflows, subscribers, preferences, and a drop-in Inbox component across in-app, email, push, SMS, and chat.
  </Card>
  <Card title="Agents" icon="bot" href="/agents">
    **Conversations your AI agents have with users.** ACI handles ingestion, identity, and delivery across Slack, Teams, WhatsApp, and more — so your agent only handles intelligence.
  </Card>
</Columns>

Same identity model. Same delivery layer. Same channels. What you learn in one carries directly into the other.

## Platform — notifications your product sends

Trigger one workflow, deliver everywhere. Novu routes notifications across channels, respects user preferences, and gives you an embeddable Inbox so you ship notification UX in minutes.

**Built for product teams who need to:**

- Send transactional and product notifications across in-app, email, push, SMS, and chat
- Let users manage their own preferences across channels
- Embed a notification center without building one from scratch
- Stay vendor-neutral across providers like SendGrid, Twilio, FCM, and more

## Agents — conversations your AI runs

Novu Connect is built on the [Agent Communication Infrastructure (ACI)](/agents/get-started/what-is-aci). It draws a hard line between **communication infrastructure** (which Novu owns) and **agent intelligence** (which you own).

Create an agent once. Make it available across every connected channel. ACI routes messages in, sends replies out, and preserves conversation context — so you never rebuild the plumbing.

<Columns cols={2}>
  <Card title="Managed agent" icon="sparkles" href="/agents/managed-agent/overview">
    Spin up a fully managed agent powered by Claude. No custom server code required.
  </Card>
  <Card title="Custom code agent" icon="code" href="/agents/custom-code-agent/quickstart">
    Bring your own logic with AI SDK, LangChain, OpenAI, or any runtime.
  </Card>
</Columns>

**Built for teams shipping AI agents that need to:**

- Talk to users on Slack, Teams, WhatsApp, and the channels they already use
- Hold stateful, context-aware conversations across sessions
- Resolve identity across platforms without rebuilding auth
- Observe and debug live agent conversations in one place
