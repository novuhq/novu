These are not available yet. This page names them so they do not grow setup guides of their own. It does not include dates. When one of them ships, its own page replaces this note.

| | What to use today |
| --- | --- |
| Voice | Telegram for a live back-and-forth, email when they can answer later |
| iMessage | Telegram or email |
| WhatsApp | Telegram or email |
| Webhooks that wake a host | `inbox list --wait`, or `inbox_list` with `wait_seconds`, from a host that is already running |
| A custom email domain | The agent's address at `agentinbox.md` |

Where the dashboard has a request control for one of these, that control records interest. There is no form on this page.
