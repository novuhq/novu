The skills are [agentskills.io](https://agentskills.io) `SKILL.md` files in their own repository, [agentinboxhq/skills](https://github.com/agentinboxhq/skills). They tell a coding agent when to read the inbox, when to send, reply, ask, approve, or choose, and how to set up the CLI and the MCP server.

`setup` ends by showing the command that installs them. Run it in the project your agent works in:

```bash
npx skills add agentinboxhq/skills
```

It installs every skill for the coding agents it finds in the project. `--agent claude-code` picks one agent, and `--skill agentinbox` picks one skill. `npx skills update` gets the latest version later.

agentinbox.md publishes the same skills, so `npx skills add https://www.agentinbox.md` installs them too.

In Claude Code, they also install as a plugin, which adds the Agent Inbox MCP server too. Sign in to Agent Inbox when Claude Code asks, or with `/mcp`.

```text
/plugin marketplace add agentinboxhq/skills
/plugin install agentinbox@agentinbox
```

Claude Code doesn't update plugins from marketplaces other than Anthropic's on its own: run `claude plugin update agentinbox@agentinbox`, or turn on auto-update for the `agentinbox` marketplace in `/plugin`.

| Skill | What it teaches |
| --- | --- |
| `agentinbox` | Ask, approve, choose, and tell; read and answer conversations; reach other contacts |
| `agentinbox-cli` | Setup, login, connect, channels, CI and sandboxes, exit codes, and errors |
| `agentinbox-mcp` | Connecting Claude, ChatGPT, Cursor, and Claude Code to the MCP server, and finishing setup there |

## When the agent should use the inbox

If you are in the chat and can answer the next message, the agent asks you there.

It uses the inbox when:

- It is running unattended: a background task, a schedule, an autonomous loop, or CI.
- The action is hard to undo: deleting data, deploying, spending money, or sending something other people will see. `approve` leaves a record of who agreed.
- The choice has several real options and guessing wrong is expensive. That is `choose`.
- A long job finished and someone should hear about it. That is a plain message, and it does not wait.

<CodeGroup>
```bash title="Belongs in the chat"
npx @agentinbox/cli inbox send ask "What should I name this variable?"
```
```bash title="Belongs in the inbox"
npx @agentinbox/cli inbox send approve "Delete 342 stale records from prod?"
```
</CodeGroup>

The first one belongs in the chat. The second one belongs in the inbox.

A chat app that already has the MCP tools does not need the skills. The operator connects it on agentinbox.md. See [Connect a host](/connect).

The skills and these docs describe the same commands. When a command changes, both change.
