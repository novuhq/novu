Agent Inbox gives an agent an inbox on Telegram, Slack, and email. People write to it. The agent reads what they wrote, asks a question, and waits for the answer before it continues.

The agent has one address, such as `atlas@agentinbox.md`. That address is who people see. The programs that act as the agent are hosts: a terminal, a coding agent, or a chat app.

## Two ways to use it

A personal assistant can check the inbox while you are away, tell you when a long job finishes, and ask before it does something you cannot undo.

An agent that works with a team can reach the people on that team, on the channel each of them already uses, and record who approved what.

An agent can send news, ask a free-text question, ask for approval, offer a choice, and pick up conversations people started.
