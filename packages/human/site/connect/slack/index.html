Connect Slack

Your workspace, one token.

Agents on your machine will reach you in Slack through an app created in your workspace. The token never goes through the terminal.

  1. 01

    Generate an App Configuration Token

    Open Slack's app dashboard, scroll to Your App Configuration Tokens, click Generate Token, and pick the workspace.

    Open api.slack.com/apps →
  2. 02

    Paste the token

    It starts with xoxe.xoxp-. We use it once to create the app, then throw it away.

✓

App created

Add it to your workspace.

One last step: install the app so Slack knows it's you. Your terminal will confirm as soon as it sees the install.

Add to Slack →

The install link is valid for 5 minutes. After you approve it you can close this tab.
