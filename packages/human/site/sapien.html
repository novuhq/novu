the human API for agents

Your agents can reach
everything — except you.

human is a tiny CLI that gives any AI agent on your machine a one-line way to text an actual person — you — on Telegram, and wait for a real answer before it does something it shouldn't do alone.

$ npx @novu/human setup

Three minutes, and it's done.

  1. 01

    You run setup, once

    Scan a QR code, link Telegram (Slack is next), and you're the default human for every agent on this machine. No account, no API keys.

  2. 02

    Your agents start asking

    Any script or agent can now call human ask, human approve, or human choose instead of guessing, and it will wait for you.

  3. 03

    You answer from your phone

    A message lands in Telegram with the question and, when it matters, buttons. Tap one, or just reply — the agent picks it up and keeps going.

what you actually see

A message, not a dashboard.

No app to check, no tab to keep open. The agent's question shows up wherever you already read messages, with enough context to decide in five seconds — and it genuinely waits for you before moving on.
