human developer portal

Reach a real person from an unattended agent, then continue from their answer.

Quickstart

npm install -g @novu/human
npx @novu/human setup
human approve "Deploy to production?" --from deploy-bot --json

The human completes setup once by connecting Telegram, Slack, or email. No account or manually-created API key is required for the keyless setup flow.

Machine output

Pass --json to receive the full interaction object. Exit codes are a stable contract and should be preferred over parsing display text.

CodeMeaning
0answered, approved, chosen, or delivered
10denied
11local wait timed out; interaction remains pending
12expired or canceled
1configuration, validation, or network error

Authentication and permissions

Setup creates a temporary keyless Novu environment and stores its identifier in ~/.novu/human.json. Existing Novu environments can set NOVU_SECRET_KEY. Headless runs also set HUMAN_TO. Read the agent authentication guide for headers, errors, and revocation.

REST reads require org:agent:read; creates and cancellations require org:agent:write. The OpenAPI document declares these requirements on each operation.

Sandbox

The keyless setup flow is the sandbox: POST /v1/inbox/session provisions a temporary environment without an account, after which the CLI configures a relay and channel. Run npx @novu/human setup to use the supported guided flow.

Direct REST access

The CLI is the supported default because it handles setup, polling, timeouts, and exit codes. Integrators that need direct access can use the API at https://api.novu.co with the published OpenAPI 3.1 specification.
